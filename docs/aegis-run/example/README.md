# EXAMPLE - NOT A REAL APP PROOF

This directory is a synthetic run generated by the Aegis Run Record CLI with
placeholder values. It exists to show the file layout and the verify output.
It is **not** a reference run, not evidence that any application works, and it
supports no claim about Aegis, any host, any model or any delivery.

## Files

| Path | Note |
| --- | --- |
| `aegis-run.json` | Example record: `schema: aegis.run-record/1`, app example-app, commit 47cc2f9e, outcome delivered. |
| `manifest.json` | Example manifest: `schema: aegis.run-manifest/1` with the record SHA-256 and artifact projection. |
| `events.jsonl` | Two synthetic events, mirrored in the record. |
| `artifacts/fe8c9ac79886-sample.txt` | The copied artifact that `verify` re-hashes (88 bytes). |
| `evidence/sample.txt` | The staging source that was copied; the record's `source` field names it. |
| `VERIFY.txt` | Captured CLI output showing PASS and the scope block. |

## Verify it

From the repository root:

```bash
python -m tools.aegis_run verify --dir docs/aegis-run/example
```

Expected output starts with `PASS` followed by:

```text
VERIFIED: record structure and copied artifact hashes only. NOT PROVEN: host/model identity, app correctness, security, delivery, universal support.
```

The CLI loads [`../schema.json`](../schema.json) and rejects any byte change,
missing artifact, missing schema or malformed field. That only proves internal
consistency for this synthetic run at verification time.

Read [the run contract](../run-record-v1.md) for the field rules and claim
limits, and [the quickstart](../README.md) for real usage.
