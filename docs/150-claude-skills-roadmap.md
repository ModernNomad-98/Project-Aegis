# Superseded: 150 Claude Skills Roadmap

This file has been superseded by the product-agnostic 300-skill roadmap:

- [`docs/300-repeatable-software-saas-skills-roadmap.md`](300-repeatable-software-saas-skills-roadmap.md)

The original 150-skill draft mixed reusable engineering skills with
product-specific domain skills. The replacement roadmap removes individual
product-feature skills and focuses on repeatable skills for software
architecture, software as a service (SaaS) architecture, engineering,
security, artificial intelligence (AI) engineering, and quality assurance
(QA).

The 300-skill roadmap and category documents under [`docs/skills/`](skills/)
preserve the strategic candidate backlog. Use the [skills catalog](skills-catalog.md)
for current shipped status. The
[version 4 (v4) reconciliation](reconciliation/step-0-reconciliation-v4.md)
preserves the historical decisions that shaped the roadmap; its generation
plan is not a current work order.
