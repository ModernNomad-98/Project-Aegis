Behavioral Eval Runner (BER) work package 2B-3 (WP-2B-3) measures the semantic judge. **Development** is the 40-case characterization stage; the **sealed holdout** is the separate 120-case one-pass measurement. `OWNER_WAIT` is the mandatory pause between them. A **source pin** is an exact reviewed Git commit and tree, not a branch name. An **allowance** is the verified unused portion of the existing call, token, and dollar ceilings, not a new budget. A **selected-host preflight** verifies the actual machine, evidence root, identity, and provider controls before any request. OD-1 is the owner's later decision on the measured result.
